# TOS + NLE Question Generator

A free, browser-based tool for nursing instructors to generate a **Table of Specifications (TOS)** and an **NLE/CHED-aligned exam** with answer key and rationales — ready to export as `.docx` files.

Built for GitHub Pages. No installation. No backend required.

---

## ✨ Features

- **TOS Generator** — user inputs subject, term (Midterm/Final), total hours, total items, and coverage areas; app auto-computes percentages and item placement.
- **Revised Bloom's Taxonomy** — full 6-level support including **Creating**.
- **Auto-Slider Distribution** — set Bloom's % with sliders; app computes per-area item placement.
- **30/70 Rule Validation** — flags if lower-order exceeds 30% or higher-order falls below 70%.
- **NLE/CHED Alignment** — every question tagged with a CHED nursing competency and an NLE blueprint domain.
- **Hybrid Question Engine** — template-based by default; optional AI toggle (Gemini/OpenAI) for richer items.
- **Exam Format** — matches institutional exam layout: header block, student info, directions, item block, signatory block.
- **Answer Key with Rationales** — every item includes an explanation aligned with NLE reasoning.
- **Export** — TOS, Exam, and Answer Key as `.docx`; full project as `.json`.
